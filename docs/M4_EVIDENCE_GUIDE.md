## 1. Missing fields (graceful display)

| Condition | Behavior |
|-----------|----------|
| `metadata.business_name` and `company_name` null/empty | Show `-` (no error) |
| `metadata.business_address` null/empty | Show `-` |
| `metadata.due_date` null/empty | **Hide Due Date row** (do not show `-`) |
| Unknown status | Show raw status with neutral badge |

Implemented in `displayOrDash()`, `shouldShowDueDate()`, and `mapTransactionSection()`.

## 3. PDF evidence fields

`buildPdfEvidenceFields(anchor)` returns:

| PDF field | Source |
|-----------|--------|
| Document number | invoice/estimate number or `reference_id` |
| Client name | `metadata.contact_name` |
| Due date | `metadata.due_date` (null if absent) |
| Document type | `metadata.document_type` or event label |
| Amount | `formatCurrency(amount, currency)` |

BP platform should map this object into the PDF template when rendering evidence downloads.
